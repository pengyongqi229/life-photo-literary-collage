# 从合成草稿到作品

素材完整、像素检查通过，只能说明合成操作正确。选文、纸幅、留白、真实显示大小仍要由执行 Agent 看图判断。`prepare.py --layout auto` 只按横竖给起点，不是构图分析器；不能把它的第一次输出直接称成品。

用户只提供生活照；以下步骤全部由 Agent 在工作区内完成。用户收到一张已选定、已复核的完成品，不接收候选草稿、阅读警告或待填写检查表。普通情况下无需向用户追问模板和审美参数。

## 先看实际画面

记录能指认的画面线索，例如车窗反射、近距离随拍、柔和阴天光、人物位置和视线；据此提出轻松、日常、安静等温和的解读。表情不足以证明“自嘲”“强撑”“释怀”等内心经历，不为配一句话替照片编故事。

从全部 69 条索引初筛后，查看最有希望的原参考图与完整文义。词条都标“松弛”不代表随便一段人生感悟都适合；说明文字里的哪一个意象、语气或观察呼应了照片。对比候选的含义、笔迹、纸色、长短及纸幅，而不是只取标签第一名。出处仍按 editorial.md 核实。

## 让纸和照片形成一个画面

用完整原参考图校准纸张所占比例、接缝和阅读节奏，不照搬原参考中的人物场景。照片是主体，纸也要有足够面积让字自然可读。上下、左右、穿页与叠纸均可；宽空白带、小纸贴在大底板中央、突兀的色块接缝都应重新审视。不要固定五五开，也不要为填满而裁纸、裁署名或改写笔迹。

也应考虑 [整页手抄纸面嵌图](paper-frame.md)：左文右图、左图右文、上图下文、上文下图。让原纸包围照片、留白连续；原纸有适合的真实空白时直接放入完整照片。必要的纸面延展只从同页干净无字区域采样，并完整保留手抄页。看全文与纸面实际情况选择，不把新方式固定成默认模板。

延展纸面需在整幅预览中检查色带、重复纹理和接缝。旧参考照片与纸面的交界可能带有一行旧场景/JPEG 渗色，不可将其当底色拉长；应检查真实裁取边界，选多行多列、有面积的纯纸纹。若采样导致绿/灰条、重复斑点或拼接色块，换采样区、纸页或布局后重做。完整原页里的字和署名不可为消接缝而擦除、混合或重排。

纸与照片分辨率相差很大时，原尺寸小纸居中不是唯一处理办法。先试更合适的素材/结构；确需整纸等比放大时，可在工作区配方中设置 `paper.allow_upscale: true` 并调整容器，同时检查原笔画与预览，不能用生成式补细节冒充高清。达到画布限制时换结构或如实说明限制，不缩小原照、不把字缩到难读来凑成品。

布局拿不准，或第一版出现上述问题时，在工作区比较另一种有理由的构图。用户仍只看选出的一个最终版本，不承担挑模板的工作。

## 两种尺寸都要看

`prepare.py` 自动生成 `preview/A.png`：整张画布 contain 缩入默认 720×1080 阅读框，不截边、不改原成图。查看这张完整预览，再以 100% 查看原纸和成图的文字/署名。预览提示的字高来自声明值，不是 OCR；没有警告也不等于文字正确或作品好看。

自定义合成、修改配方或比较多个布局后，重新生成对应预览，不能拿上一版预览复核新版：

```bash
python <skill>/scripts/preview.py result-v1 result-v2 --out comparison-v1
```

查看 `comparison-v1/comparison.png` 与各自的 A/B 完整图；可用 `--width 480 --height 800` 模拟更小的显示框。字读不清、纸幅失衡、署名不可见或情绪牵强时回到素材/布局选择。修改后重新运行像素验证、预览和逐字复核，最后才填写 `review.json` 并通过 `verify.py --require-review`。

交付原尺寸最终 PNG 与简短选文理由。宿主缩略图若裁切或只显示局部，同时给原文件下载入口，并查看完整文件确认；不能凭聊天缩略图认定源文件已截字，也不能用“分辨率高”代替观看效果。

Agent 完成内部审美与来源复核后，运行 `finalize.py <result> --assets <assets> --preview <当前预览目录> --out <新的交付目录>`。该入口确认预览对应当前文件，并执行严格像素/复核验证，最后只导出一张 PNG。它不能代替 Agent 的审美判断；不得自动把真实作品的复核项全部设为 true。
