# 交付前检查

## 自动检查确实证明什么

`compose.py` 生成后立即调用同一版本验证器；`verify.py` 可独立重跑，输入仍需调用者原素材目录。验证器不只相信 manifest 或遮罩，而是按配方从原素材重建全部预期 PNG，再比较源文件 SHA-256、解码像素、布局、所有输出文件哈希和每个像素。

未调色原照必须与源图解码像素一致。合成以 `photo-graded.png` 为比较基准：所有照片像素在画布底层恰好出现一次，重组后与调色图零差异；叠纸覆盖区外同样必须与调色图零差异。记录调色图相对原照的真实变化量；仅当关闭调色时才可承诺它与原照像素完全一致。遮罩来自实际纸层的非零 alpha，不允许用任意大矩形掩盖照片改动。

纸张必须整页放入，正文/署名框必须位于原图和输出内，声明的最小字高必须达到设置下限，主体保护框必须不受叠纸或分割线影响。原图文件不写回。RGBA 比较覆盖全部四个通道，不能只用差异图的 alpha 判断 RGB 是否变化。

整纸嵌图版还验证照片四周留纸、照片与全文/署名框的安全距离及实际左右/上下关系；嵌入区域无纸层覆盖，每个照片像素对应调色底图。完整原纸页保存在 `paper-surface.png`；延展按源纸、采样框、固定种子和方法重新计算，最终文字区域与未嵌图纸底对应像素一致。采样区与已标文字框相交时拒绝，不用文件哈希代替重算。

## 自动检查不能证明什么

- 原素材上传前有没有截字、漏署名或虚化；执行者是否漏标正文范围。
- 转录是否逐字正确、作者/作品是否真实、版权证据是否足够。
- 字是否在手机实际观看时可读，纸是否太透明，留白是否失衡，文学是否匹配情绪。
- 复核 JSON 的填写者是否如实检查。它是留痕，不是内容真实性认证或数字签名。

## 必须目视填写的 review.json

先按 [构图与审美复核](aesthetic-review.md) 打开整张画布的阅读尺寸预览，再以 100% 放大对照原纸和成品。`prepare.py` 自动返回 `preview_image`；自定义/修改后的输出运行 `preview.py` 生成，必须对应当前成图。预览只缩放副本，不改变原尺寸交付文件。逐项填 `true`，填写 `checked_by` 与必要的 `notes`。任一项不能确认就先保留 `false` 并解决问题：

| 检查键 | 对照内容 |
| --- | --- |
| `full_text_and_punctuation` | 每行、每字、所有标点、行末笔画均完整，原有换行未被重排 |
| `signature` | 署名/落款完整、清晰、未被当成边角杂物删掉 |
| `source_page_complete` | 原素材本身无截字；全纸轮廓、上下左右及打孔均保留 |
| `paper_texture_and_edges` | 原纸纹理存在、边缘可辨，透景时不退化为浮字或光斑 |
| `legibility` | 阅读尺寸预览中笔画、浅字和小署名可读；不是只在原始大图 100% 下可读；透明度没有削弱阅读 |
| `subject_unobstructed` | 脸、手和关键场景未被遮挡或切开；保护框无漏标 |
| `mood_and_layout` | 选文有具体画面依据，纸幅/留白/接缝协调；没有无意的宽空白带或邮票般小纸；不加票根印章等装饰 |
| `attribution_and_rights` | 原文/作者/作品及文本、译文、图像使用依据均已核实并留证 |
| `photo_look_natural` | 对照未调色原照，肤色自然、黄蓝关系保留、亮部不灰、颗粒不显眼；不调色模式确认零变化 |
| `paper_extension_natural` | 仅纸面延展版新增：采样确实无字无旧场景污染；没有绿/灰色带、明显重复纹理、突兀接缝或色块；完整原手抄页与所有文字保留 |

```bash
python scripts/verify.py result-v1 --assets /path/to/materials --require-review
```

未全通过时返回非零，`delivery_ready` 不得为 `true`。验证失败会清除前次成功报告并记录失败，防止旧报告被误认成新成品有效。换 Pillow 版本重算纸张缩放可能不同，记录生成版本并在需要时使用同版重查。

## 交付

最终一张无损 PNG、简短选文/调色与必要来源说明；原照、底图和验证记录留在工作区，需要时提供。聊天缩略图若裁边，给完整文件入口并查看完整文件再判断署名是否截断。不把多个未验证方案混称为成品。调用者当次上传的生活照与私有运行结果不并入 Skill ZIP；维护者明确共享的原参考包仍完整随包。
