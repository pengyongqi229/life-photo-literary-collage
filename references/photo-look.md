# 轻微日系复古胶片调色

照片保留真实感，调色增加氛围，手抄保留原始质感。默认预设 `japanese-film`：微暖、柔和对比、少量收敛饱和度、轻抬暗部及极轻微单色颗粒。不是发灰蒙雾、重度泛黄或模糊磨皮；照片里的金黄与蓝色等对比仍须鲜明自然。

```json
"look": {"preset": "japanese-film", "strength": 0.45, "grain": 0.35, "seed": 1729}
```

以上对象放在配方的 `photo` 对象中。未填写 `photo.look` 时同样默认应用该预设。`strength` 和 `grain` 均在 0–1 之间；`seed` 为 0–4294967295 整数。`strength` 默认 0.45，优先根据实际照片向下调整；数值不是模仿某款胶卷的科学标定。`grain` 控制稀疏单色颗粒密度，默认仅约 16% 像素受 ±1 级 RGB 同步微扰，不改变主体轮廓。

## 原像素要求优先

用户要求“不调色”或“每个原像素都不变”时，显式关闭：

```json
"look": {"preset": "none"}
```

`strength: 0` 也为恒等处理。关闭时 `photo-graded.png` 与未调色原照逐像素一致。不要把“保留原照文件”与“调色后像素不变”混为一谈。

## 保真与可复查

1. 原素材文件不写回；`photo-native.png` 原尺寸保留未调色像素。
2. 只在照片副本上执行传统颜色运算，得到 `photo-graded.png`；不使用生成模型，也不改变构图、尺寸、人物、细节或原 ICC 配置。
3. 先处理完整照片，再进行穿页或搬移；颗粒使用固定随机种子，验证时可逐像素重算。
4. 手抄图的颜色、文字、署名、纸纹不受照片调色影响。
5. 合成校验的基准是调色底图，记录与原照的实际差异；关闭调色才能承诺其 RGB 与原照零差异。

实现使用当前输入 ICC 对应的 8 位 RGB 数值，不做色域转换；不同输入色域下效果可能不同，需目视核对。验证记录保存预设、强度、颗粒、种子、算法版本、原照/调色图像素哈希，以及最大/平均通道变化量。旧引擎生成的成品需使用对应旧版本验证器。

交付前必须对照原照和调色图检查：肤色不偏、亮部不灰、暗部不糊、原有黄蓝对比未被压掉、颗粒不显眼。若环境本来就偏暖或低对比，降低强度或关闭，不强行套同一效果。
