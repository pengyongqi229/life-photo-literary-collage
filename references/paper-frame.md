# 整页手抄纸面嵌图

`layout.type: paper-frame` 让真实手抄纸面包围照片，纸边与文字区的留白连贯。它与上下/左右分栏、三段穿页、场景内半透明叠纸一起参与构图选择，不是新的唯一模板。定位草图中的线条不加入完成品。

| `photo_side` | 图文关系 |
| --- | --- |
| `right` | 左文右图 |
| `left` | 左图右文 |
| `top` | 上图下文 |
| `bottom` | 上文下图 |

照片按 EXIF 显示方向、原尺寸、整数坐标粘贴，不缩放或裁切。手抄整页保留，不能拆字、重排段落、擦字或遮住正文、标点、落款。字段里的坐标全部由 Agent 看本次实图后填写，用户不需要提供配方。

## 原纸留白足够：embed

`mode: embed` 直接使用完整原纸作画布，`paper_xy` 必须为 `[0,0]`，`canvas_size` 必须等于整纸按 `paper_scale` 等比适配后的尺寸。照片位于真实无字留白里，四周至少留出 `border` 像素纸面。示意（坐标仅举例，不能套用到未核对的素材）：

```json
{
  "type": "paper-frame",
  "mode": "embed",
  "canvas_size": [960, 960],
  "paper_xy": [0, 0],
  "paper_scale": 1,
  "photo_xy": [650, 380],
  "photo_side": "right",
  "border": 40,
  "text_clearance": 12
}
```

`photo_xy` 是完整照片的左上角；宽高严格取自照片原图。`paper_xy` 是完整手抄页左上角；`paper_scale` 默认 1，确需放大整纸须显式设置 `paper.allow_upscale: true` 并复核笔迹。照片与所有正文/署名框保持 `text_clearance`，方向关系也会检查；宽泛的 OCR 草稿框应先精确核对，不能删除框来绕过保护。

## 原纸不够容纳完整照片：extend

优先换用留白更合适的真实纸页。确需扩展时，`mode: extend` 设置更大的 `canvas_size` 和合适的 `paper_xy`/`photo_xy`，增加：

```json
"extension": {
  "sample_box": [20, 20, 300, 300],
  "blank_sample_confirmed": true,
  "seed": 1729,
  "patch_size": 192,
  "overlap": 32
}
```

采样坐标相对未缩放的所选原纸。必须查看原图确认是**有面积、无字、无标点、无署名、无孔洞的真实纸纹**，与声明文字框保持安全距离；最小 64×64。不采用照片场景、印记、旧成品背景或一行/一列边缘像素。参考成品的图纸交界可能混有旧场景与 JPEG 渗色，先核对真实纸区裁取边界；避开绿/灰边线等污染，用多行多列干净纸纹估计底色并保留空间纹理，不能把单条像素拉长形成色带。

脚本只从该区域取真实纹理块，以固定种子的随机偏移/镜像、重叠区匹配和局部拼接混合延展。延展先在原纸分辨率的工作画布上完成，再随整纸比例放大/缩小，避免外围纤维比放大后的原纸更细。全幅铺纸后，再原样粘贴完整原手抄页，因此原纸页不参与纹理混合、擦除或分段重排。`paper-surface.png` 保存未被照片遮盖前的完整纸底，原图文件也只读保留。元数据记录原纸哈希、采样框/像素哈希、面积均色、种子、块尺寸、重叠、纹理工作尺寸/输出比例与方法版本；验证器用原素材独立重算。

照片只覆盖无字区域；即使原纸有透明孔洞也不能用照片盖住孔洞。全部文字和署名区域在最终图中必须与未嵌图纸底对应像素一致。纸边保持可辨，不添加红线、描边、印章、胶带或假做旧。

## 执行与验收

Agent 将布局对象写入工作区 `frame.json`：

```bash
python <skill>/scripts/prepare.py --photo <原照片> --paper-id <选中页> --layout paper-frame --frame-file frame.json --out work-v1
```

OCR 草稿仍需 `--transcript-file`、`--regions-file` 与准确纸区；需要放大整纸时加 `--allow-paper-upscale`。也可直接在 `compose.py` 的完整配方中使用上述 `layout` 对象。按宿主可用内存配置资源时，用 `--resources-file resources.json` 或完整配方里的 `resources`；不能为适应上限缩小照片。

自动验证原照保留、嵌入后每个照片像素对应完整调色底图、文字框不受遮挡、纸底重算一致。Agent 还必须查看完整阅读预览和 100% 局部，核对字迹/署名、纸面包围关系、放大后纸纹尺度、原页接界纸色、重复纹理、接缝和绿/灰色带。延展版新增 `review.json` 项 `paper_extension_natural`，未确认时 `finalize.py` 拒绝完成品导出。无字判定、漏标文字和纹理审美不能由像素校验自动证明。
