# 随包原参考素材说明

`参考图.zip` 是维护者提供的原压缩包，完整原样随 Skill 分发，包含全部 69 张参考图，没有删减、重编码或替换。压缩包 SHA-256 和字节数记在 `reference-archive.json`。维护者已明确要求让安装者同时下载这套素材到本地，以后只上传生活照即可使用。

首次使用由 `scripts/library.py` 自动解压。每张解压图片的文件字节与原 ZIP 成员完全相同，使用安全的本地编号文件名保留原图；原文件名映射在 `catalog.json`。只在选中后按完整纸区裁取手抄，不在安装前缩减成少数可用页。不加入调用者后来上传的生活照或私有运行结果。

索引的内容摘要、情绪标签、OCR 草稿和核对提示仅帮助寻找；不是已经核实的全文、文学出处或素材质量结论。原图有透景、书页背景或没有可见落款时，由 Agent 在当次选中后核对，不因此从 69 张检索库删除。保留全部可见文字、标点、署名和纸纹，不重绘原图或抹字重建。

库里没有合适且能完整使用的手抄时，再查证外部文学片段、作者及出处，制作注明“手写风排印”的新页。不得冒充真实手抄或作者亲笔。字体按随包 OFL 许可证分发。

素材由维护者提供，不等于其所含文学原作、译文、摄影或书写图像的权利链已经全部核实；也不把第三方作品转成 MIT 授权。代码许可证不自动覆盖参考素材。成品前仍须按 `references/editorial.md` 核实文本、归属及适用使用依据，不可伪造复核记录。
