# 手写风排印字体

`LongCang-Regular.ttf` 来自 Google Fonts 的 Long Cang 字体，按随包 `OFL-LongCang.txt` 的 SIL Open Font License 1.1 分发，不适用本项目 MIT 许可证。字体文件保持原样。

- 字体源：https://github.com/google/fonts/tree/main/ofl/longcang
- 字体说明：https://github.com/google/fonts/blob/main/ofl/longcang/DESCRIPTION.en_us.html
- 许可证：https://github.com/google/fonts/blob/main/ofl/longcang/OFL.txt

字体仅用于“素材库无合适片段”时的新文字排印；不用于替换真实手抄笔迹，不伪装成文学作者亲笔。运行时无须使用者寻找或安装字体。
